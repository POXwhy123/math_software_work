# W01-001：浏览器会话失效与恢复

2026-11-12 · [第 1 周笔记](../02-每周笔记/第01周.md) · [GeoGebra 源文件](../06-课程成果/第01周/source/week01-basic-objects.ggb)

## 现象

第一次检查已经导出了 .ggb。随后对原会话运行 `snapshot`，Playwright CLI 返回退出码 1，提示找不到已打开的浏览器。

```text
The browser 'math-week01' is not open, please run open first
```

原会话关闭的原因未查明。

## 恢复和复验

新开一个 Chrome 会话，进入 GeoGebra Classic。复验脚本读出磁盘上已经保存的 .ggb，计算 SHA-256，再用 `setBase64` 把该文件载入网页。

重开时 A=(-2,1)，B=(4,3)，M=(1,2)。用 Playwright 拖动 A 到 (-3,2)，B 留在原处，M 变成 (0.5,2.5)，圆也随之更新。脚本核对了自由点和依赖对象，结果通过。
