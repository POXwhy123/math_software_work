## 复现与人工检查

在仓库根目录执行以下标准库检查，无需安装 Python 包：

```powershell
python tools/check_structure.py
python tools/validate_week01.py
```

需要重新执行浏览器检查时，使用独立会话，以免改动本人已打开的文件：

```powershell
npx.cmd --yes --package @playwright/cli@0.1.24 playwright-cli -s=math-week01 open https://www.geogebra.org/classic --browser chrome
python tools/week01_reopen_check.py
```

脚本在浏览器里载入 .ggb、拖动点并恢复初始状态。复验会生成新的 JSON 和截图。若更换验收材料，请重新核对和打包。

人工检查步骤：在 Obsidian 中打开内层仓库，确认主页可到达本周笔记、个人档案和成果；在 GeoGebra 打开 .ggb，选择移动工具并拖动蓝色 A、B，检查橙色 M 始终为中点，圆心为 M 且圆经过两端点。本次已经验证网页版；本机 Calculator Suite 的打开与拖动尚未人工确认。
