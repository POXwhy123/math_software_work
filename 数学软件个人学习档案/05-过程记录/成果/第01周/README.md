# 第 01 周成果：工具环境、学习档案与基础对象

本周练习用两个自由点构造线段、中点和圆。启动清单补充版待复核。学习档案、素材索引、环境和问题记录可从 [本周笔记](../../每周笔记/第01周.md) 打开。

| [展示笔记](../../../04-展示材料/第01周/基础对象展示.md) | 初始图形、拖动与重开预览 | 已整理 |

用 GeoGebra 打开 .ggb 后选择移动工具，拖动蓝色 A 或 B，观察橙色中点 M、灰色线段与青色圆随之更新。初始 A=(-2,1)、B=(4,3)、M=(1,2)，圆为 (x−1)²+(y−2)²=10。源文件没有外部素材依赖。

Chrome 里的 GeoGebra Classic（API 版本 5.4.936.0）已完成端点拖动和磁盘文件重开检查。迁移后已从 Obsidian 在桌面版 GeoGebra 打开文件，移动 B 后中点和圆跟随更新。

在仓库根目录运行 `python tools/validate_week01.py`，可以检查 .ggb 的对象依赖和运行记录是否与文件对应。浏览器复验命令见验收说明。
