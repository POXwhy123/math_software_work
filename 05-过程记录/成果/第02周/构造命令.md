# 三角形四心的构造命令

在 GeoGebra Classic 新建文件，依次输入下面各行。先画三条边，再建它们所在的直线，供作高和量边距使用。

```text
A = (-5, -2)
B = (5, -2)
C = (-2, 3)
a = Segment(B, C)
b = Segment(C, A)
c = Segment(A, B)
sideA = Line(B, C)
sideB = Line(C, A)
sideC = Line(A, B)
```

## 重心 G

```text
D = Midpoint(B, C)
E = Midpoint(C, A)
F = Midpoint(A, B)
mA = Segment(A, D)
mB = Segment(B, E)
mC = Segment(C, F)
G = Intersect(mA, mB)
```

## 垂心 H

```text
hA = PerpendicularLine(A, sideA)
hB = PerpendicularLine(B, sideB)
hC = PerpendicularLine(C, sideC)
H = Intersect(hA, hB)
```

## 内心 I

三个点版的 `AngleBisector` 取第二个点作角顶点。内切圆半径取 I 到 AB 所在直线的距离。

```text
iA = AngleBisector(B, A, C)
iB = AngleBisector(C, B, A)
iC = AngleBisector(A, C, B)
I = Intersect(iA, iB)
ri = Distance(I, sideC)
inc = Circle(I, ri)
```

## 外心 O

```text
oA = PerpendicularBisector(B, C)
oB = PerpendicularBisector(C, A)
oC = PerpendicularBisector(A, B)
O = Intersect(oA, oB)
circ = Circle(O, A)
```

源文件中，左上角四个复选框分别控制各组辅助线的显示。作高用的三条底边直线在画板上隐藏，定义仍可在代数区查看。[四心源文件](../../../01-GeoGebra/第02周/第2周-三角形四心.ggb) · [周笔记](../../每周笔记/第02周.md)
