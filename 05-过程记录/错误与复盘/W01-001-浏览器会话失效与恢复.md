# W01-001：浏览器会话失效与恢复

2026-11-12 · [第 1 周笔记](../每周笔记/第01周.md) · [GeoGebra 源文件](../../01-GeoGebra/第01周/第1周-基础对象.ggb)

## 现象

第一次检查已经导出了 .ggb。随后对原会话运行 `snapshot`，Playwright CLI 返回退出码 1，提示找不到已打开的浏览器。

```text
The browser 'math-week01' is not open, please run open first
```

命令找不到已打开的命名会话。最初的会话为何关闭，仍未查明。

## 复现会话未打开

在独立会话中先打开空白页，然后关闭会话。在关闭后对同名会话运行 `snapshot`。

```powershell
npx.cmd --yes --package @playwright/cli@0.1.24 playwright-cli -s=math-week01 open about:blank --browser chrome
npx.cmd --yes --package @playwright/cli@0.1.24 playwright-cli -s=math-week01 close
npx.cmd --yes --package @playwright/cli@0.1.24 playwright-cli -s=math-week01 snapshot
```

2026-11-17 实测出现上面的同一条报错，退出码为 1。

## 恢复和复验

新开一个 Chrome 会话，进入 GeoGebra Classic。复验脚本读出磁盘上已经保存的 .ggb，计算 SHA-256，再用 `setBase64` 把该文件载入网页。

重开时 A=(-2,1)，B=(4,3)，M=(1,2)。用 Playwright 拖动 A 到 (-3,2)，B 留在原处，M 变成 (0.5,2.5)，圆也随之更新。脚本核对了自由点和依赖对象，结果通过。2026-11-17 复现报错后，再用改名后的 `第1周-基础对象.ggb` 重开和拖动，检查通过。
