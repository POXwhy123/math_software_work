# 数学软件个人学习档案

在 Obsidian 中选择“打开本地仓库”，选中本仓库下的 `数学软件个人学习档案` 文件夹，再打开 [课程主页](数学软件个人学习档案/05-过程记录/00-首页.md)。档案覆盖第 1–11 周，第 1 周已有 GeoGebra 源文件和运行记录。课程范围见 [总任务 #1](https://github.com/POXwhy123/math_software_work/issues/1)。

```text
数学软件个人学习档案/
├── 01-GeoGebra/
├── 02-计算实验/
├── 03-LaTeX/
├── 04-展示材料/
└── 05-过程记录/
```

| 目录 | 内容 |
| --- | --- |
| `01-GeoGebra/` | GeoGebra 的 .ggb 源文件 |
| `02-计算实验/` | 计算步骤、命令和结果的 Obsidian 笔记 |
| `03-LaTeX/` | LaTeX 的 .tex 源文件 |
| `04-展示材料/` | 展示笔记及其图片等附件 |
| `05-过程记录/` | [个人学习档案](数学软件个人学习档案/05-过程记录/课程计划/个人学习档案.md)、每周笔记、案例、错误和验收记录 |

第 1 周的构造和预览见 [验收说明](数学软件个人学习档案/05-过程记录/成果/第01周/验收说明.md)。笔记用相对链接引用源文件，目录要求见 [Issue #13](https://github.com/POXwhy123/math_software_work/issues/13)。

在 Git 仓库根目录运行以下检查。

```powershell
python tools/check_structure.py
python tools/validate_week01.py
```

[环境记录](数学软件个人学习档案/05-过程记录/课程计划/本地环境检查.md)列出了各软件及复验方法。每周材料经本人验收后，可将获准版本推送到对应分支。
